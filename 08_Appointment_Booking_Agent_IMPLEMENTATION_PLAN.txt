1. ТЕХНИЧЕСКОЕ РЕШЕНИЕ

Выбранный стек:

- TypeScript;
- Node.js;
- Express для серверной части и API админки;
- Telegraf для Telegram-бота;
- React + Vite для админ-панели;
- Prisma для работы с базой;
- SQLite для базы MVP;
- date-fns и date-fns-tz для дат и часового пояса;

Пояснение:
MVP должен запускаться локально и быть понятным для портфолио.
SQLite проще для демонстрации, Prisma позволит позже перейти на PostgreSQL.

11. SLOTSERVICE

SlotService отвечает только за свободные окна.

Он должен учитывать:

- длительность услуги;
- буфер до услуги;
- буфер после услуги;
- рабочие часы;
- перерывы;
- выходные;
- блокировки времени;
- уже существующие активные записи;
- часовой пояс UTC.

Правило пересечения:
Слот занят, если у того же специалиста есть активная запись, где начало старой записи раньше конца нового слота, а конец старой записи позже начала нового слота.

Активные статусы для проверки занятости:

- confirmed;
- needs_attention.

Неактивные статусы:

- canceled;
- rescheduled;
- completed;
- no_show.
